## [0.1.0] - 2026-10-04

### Added

- Four README variants: Flagship, Engineering, Minimal, Launch.
- Four agent skills: `readme-forge`, `oss-launch`, `profile-readme`, `badge-ci`.
- Open-source kit: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, issue and PR templates.
- CI for this repository: kit validation and Markdown linting.
- Profile README hub and SVG assets (banner, social preview).
- Documentation: pattern research, variant guide, launch checklist, dynamic badges.
